# Key Layout Manager 1.1.1

A maintenance update to app icon packaging and installation.

- Remove an unused image from the app icon asset set to avoid asset compiler warnings.
- Add a signed and notarized PKG installer that installs Key Layout Manager into Applications.

Download **KeyLayoutManager_1-1-1.pkg** and open it to install, or unzip **KeyLayoutManager_1-1-1.zip** and move **KeyLayoutManager.app** to Applications. Existing users can choose **Check for Updates…** in the app menu.

Requires **macOS 14 or later** and an **Apple silicon Mac**.
